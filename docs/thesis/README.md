## Требования

- ГОСТ 7.32-2017, шрифт Times New Roman 14pt, межстрочный 1.5, отступ 1.25.
- Объём основной части ≥60 стр. (Введение + главы 1–4 + Заключение).
- Оригинальность ≥80%, заимствования ≤15%.
- Стиль безличный («В работе проведено …»).
- Подробности и порядок этапов — в `PLAN.md`.
