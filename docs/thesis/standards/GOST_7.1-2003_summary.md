# Summary ГОСТ 7.1-2003 «Библиографическая запись. Библиографическое описание. Общие требования и правила составления»

Утверждён постановлением Госстандарта № 332-ст от 25.11.2003, введён в действие с 01.07.2004. На территории РФ с 01.07.2019 действует также **ГОСТ Р 7.0.100–2018** (ГОСТ 7.32-2017 рекомендует именно его, п. 5.10.1), однако **ГОСТ 7.1-2003** остаётся базовым опорным документом и формально указан в перечне нормативных ссылок ГОСТ 7.32-2017.

> Для целей этой ВКР список литературы оформляется по ГОСТ 7.1-2003 (в соответствии с тем, что явно указано кафедрой 806 МАИ).

---

## 1. Зоны (области) одноуровневого библиографического описания (раздел 5)

В порядке следования (для книги):

1. **Область заглавия и сведений об ответственности** — основное заглавие [: сведения, относящиеся к заглавию] / первые сведения об ответственности ; последующие сведения об ответственности.
2. **Область издания** — сведения об издании / сведения об ответственности к этому изданию.
3. **Область специфических сведений** (для отдельных видов: карты, ноты, сериальные издания и т. п.).
4. **Область выходных данных** — Место издания : Издательство, Год.
5. **Область физической характеристики** — Объём (страницы, листы).
6. **Область серии** — (Заглавие серии ; № выпуска).
7. **Область примечания**.
8. **Область стандартного номера (ISBN/ISSN) и условий доступности**.

## 2. Предписанная пунктуация (условные разделители)

| Знак | Назначение |
|------|-----------|
| `. —` (точка, пробел, тире, пробел) | разделитель **областей** описания |
| `:` (двоеточие) | перед сведениями к заглавию; перед издательством |
| `/` (косая черта) | перед первыми сведениями об ответственности |
| `;` (точка с запятой) | перед последующими группами сведений об ответственности; между местами издания при нескольких |
| `,` (запятая) | перед годом издания; между однородными сведениями |
| `()` (круглые скобки) | для области серии |
| `[]` (квадратные скобки) | для сведений из источников вне предписанного источника (например, `[Электронный ресурс]`) |
| `//` (две косые черты) | в **аналитическом** описании — перед сведениями о документе, в котором помещена часть (статья в журнале) |

**Принцип**: предписанная пунктуация ставится **перед каждой областью или элементом** (а не после), кроме первой области (заглавия). Пунктуация ставится через пробел с обеих сторон (`. —`, ` : `, ` / `, ` ; `).

## 3. Образцы по типам документов

### 3.1. Книга одного автора
```
Обоскалов В. П. Технологические аспекты эксплуатации электрических систем : учеб. пособие / В. П. Обоскалов. — Екатеринбург : УГТУ-УПИ, 2009. — 194 с.
```

### 3.2. Книга 2–3 авторов
```
Селезнева И. С. Биоэнергетика : учеб.-метод. пособие / И. С. Селезнева, Е. В. Садчикова. — Екатеринбург : УГТУ-УПИ, 2006. — 59 с.
```

### 3.3. Книга 4 и более авторов
Заголовок описания — заглавие; сведения об авторах после `/`:
```
Моделирование систем с использованием информационных технологий : учеб. пособие / В. Г. Лисиенко, Н. Г. Дружинина, О. Г. Трофимова и др. — Екатеринбург : УГТУ-УПИ, 2009. — 440 с.
```

### 3.4. Издание под редакцией
```
Российская энергетика — 2009: совершенствование теплотехнического оборудования... : материалы VI междунар. науч.-практ. конф. / отв. ред. Ю. М. Бродов. — Екатеринбург : УГТУ-УПИ, 2009. — 244 с.
```

### 3.5. Статья в журнале (аналитическое описание)
```
Фукуяма Ф. Конец истории? / Ф. Фукуяма // Вопросы философии. — 1990. — № 3. — С. 134–155.
```
**Особенность**: после `//` — заглавие журнала, затем `. — Год. — Том/Номер. — Страницы.`

### 3.6. Статья в сборнике трудов конференции
```
Ильин А. В. Пути повышения КПД гидрообъёмных трансмиссий / А. В. Ильин, Ю. И. Багин // Проблемы и достижения автотранспортного комплекса : сб. материалов VI Всерос. науч.-техн. конф. / отв. ред. Т. М. Смирнов. — Екатеринбург : УГТУ-УПИ, 2008. — С. 112–114.
```

### 3.7. Электронный ресурс
```
Трифонов С. И. Технологический процесс... / С. И. Трифонов. — URL: http://rd.feb-web.ru/trifonov-09.html (дата обращения — 28.12.2012 г.).
```

Для электронных ресурсов ГОСТ 7.82-2001 предписывает в общем обозначении материала указывать `[Электронный ресурс]`, а в области примечания — URL и дату обращения.

### 3.8. Диссертация
```
Рут М. Э. Образная номинация в русском языке: ономасиологический аспект : дис. … д-ра филол. наук / Рут Мария Эдуардовна. — Екатеринбург, 1994. — 192 с.
```

### 3.9. Автореферат диссертации
```
Вишняков И. В. Модели и методы оценки коммерческих банков в условиях неопределённости : автореф. дис. … канд. экон. наук / И. В. Вишняков. — М., 2002. — 16 с.
```

### 3.10. Зарубежное издание (книга)
```
Freeman R. E. Strategic management: A stakeholder approach / R. E. Freeman. — B. : Pitman Publishers, 1984. — 276 p.
```
(Зарубежные издания указываются после отечественных, поскольку язык работы — русский.)

### 3.11. Статья в зарубежном журнале
```
M. Kress. Collecting Cosmic Dust / M. Kress // Mercury Magazine. — 2001. — Vol. 30, № 6. — P. 24.
```

### 3.12. ГОСТ (стандарт)
ГОСТы цитируются по правилам аналогично официальным документам. В тексте отчёта о НИР допускается указывать только обозначение без года при условии полного описания в списке источников (ГОСТ 7.32-2017, п. 6.9.3).

## 4. Сокращения

- ГОСТ 7.12-93 регламентирует сокращение слов на русском языке (например, «учеб. пособие», «сб. науч. тр.», «изд-во», «ред.», «отв. ред.», «дис. …», «автореф.»).
- ГОСТ 7.11-2004 — сокращение слов на иностранных европейских языках.
- **Не сокращают** заглавия (за исключением случаев, когда сокращение есть в самом источнике) и общее обозначение материала.

## 5. Особенности оформления списка источников

- **Структурирование**: при большом числе разнотипных источников рекомендуется группировать (источники, словари, литература, электронные издания). Доля электронных изданий — **не более 30 %** от всей литературы.
- Список нумеруется арабскими цифрами с точкой; печатается с абзацного отступа (ГОСТ 7.32-2017, п. 6.16).
- Порядок — по появлению ссылок в тексте отчёта (ГОСТ 7.32-2017, п. 6.16; либо по алфавиту, если так предписано выпускающей кафедрой).

## 6. Отсылки в тексте (внутренние ссылки на список литературы)

Для оформления отсылок в тексте отчёта о НИР используется числовая система `[N]` или `[N, c. M]`. Альтернативный стиль `[Иванов, 2003: 234]` — применяется в работах гуманитарного цикла, для технических ВКР рекомендуется числовая система (ГОСТ 7.32-2017, п. 6.9.1).
