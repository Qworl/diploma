## Ключевые количественные результаты для глав

- 22 целевых атрибута в трёх категориях OFF (pasta 8, chocolate 7, beverages 7).
- На валидном подмножестве 15 атрибутов из 22 (§3.1):
  - средняя точность regex_ml_bayes 90.2%;
  - среднее покрытие 78%;
  - 9 атрибутов с лифтом ≥10 п.п. над тривиальной базой.
- Вклад слоёв (§6.13): regex 11% решений / 92.6% точности, ML 67.8% / 89.2%, Bayes 5.2% / 51.3%, LLM-fallback 16.1%.
- Cascade vs direct LLM (§6.11): на нутри-полях каскад строго лучше (+13..+58 п.п.), на ярких категориальных direct LLM на 2–9 п.п. лучше при втрое большей цене.
- USDA-эксперименты: B (lookup-слой) даёт +47% acc на 100% хвоста beverages/sugar_class — единственный значимый положительный эффект.
