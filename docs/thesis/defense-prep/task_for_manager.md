  1. PO-loop как явный паттерн                                                                                                    
                                                                                                                                  
     ┌─────────────────────────────────────────┐
     │                                         │                                                                                  
     ▼                                         │                                                                                  
  [review] ──► [propose next spec] ──► [execute] ──► [close + retro]
     ▲                                                       │                                                                    
     │                                                       │                  
     └───────────────────────────────────────────────────────┘                                                                    
                                                                                
  Цикл идёт не «спека за спекой по плану», а с переоценкой приоритета на каждой итерации. То есть после закрытия Workstream A я не
   автоматически открываю B — я сначала смотрю, не появилось ли чего-то более важного (новый комментарий научрука, найденный
  косяк, неуспешный тест).                                                                                                        
                                                                                                                                  
  2. Три новых файла в репо                                                                                                       
                                                                                                                                  
  docs/thesis/defense-prep/BACKLOG.md — приоритизированный список идей. Живёт вне любых спеков. Структура:                        
                                       
  ## P0 (блокирует защиту)                                                                                                        
  - [ ] ...                                                                     
                                                                                                                                  
  ## P1 (сильно поднимает качество)    
  - [ ] ...                                                                                                                       
                                                                                
  ## P2 (nice-to-have)                                                                                                            
  - [ ] ...                                                                                                                       
                                                                                                                                  
  ## Закрыто                                                                                                                      
  - [x] ... (дата + ссылка на коммит)                                                                                             
                                                                                
  Backlog пополняется из трёх источников: (а) моих периодических обзоров, (б) ваших новых комментариев, (в) того, что находится во
   время исполнения спека.
