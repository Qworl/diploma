### 3.4. Статистическая защита headline (на Slide 9)

**Не Wilson CI overlap.** Wilson CI текущего headline и pre-deploy могут перекрываться при близких значениях — overlap test не доказывает значимость.

**Правильно:** paired McNemar на **общих 4350 ячейках** между текущей и предыдущей конфигурациями. На слайде:
```
| Метрика                    | Значение               |
| Headline accuracy          | <X> % (Wilson 95% CI [a; b]) |
| McNemar vs pre-deploy      | p = <p_value>          |
| McNemar vs all-sonnet      | p < 0.001 (ожидаемо)   |
```

Если paired McNemar **не достигает p < 0.05** vs pre-deploy → headline формулируется как «**сопоставимая точность при сокращении / повышении другого показателя**», а не «значимое превосходство».

## 11. Риски и mitigation

| Риск | Mitigation |
|---|---|
| Headline числа меняются ещё несколько раз | Спека работает с placeholders; sync — отдельная процедура §3 |
| Paired McNemar vs pre-deploy даёт p > 0.05 | Headline формулируется как «сопоставимая точность при …», не «значимое превосходство» |
| Wilson CI текущей и pre-deploy overlap | Не использовать как тест значимости; paired McNemar — единственный |
| PDF задания не получен вовремя | Запросить у Крылова немедленно; параллельно работать |
| 14 слайдов не вписываются в тайминг | Готов план compression до 10-12 (объединить slides 2+3, 11+12; перенести 7 в backup) |
| `reproduce.sh` упадёт при аудите | Phase 0 task, чинить до коммита QR |
| Антиплагиат < 80 % | Запустить за 10+ дней до дедлайна |
| ml_service не запустится для скриншотов | Pre-bake скриншоты NOW в Phase 1 (когда ml_service ещё точно работал в недавнем прошлом) |
| Нормоконтроль кафедры даст замечания | Запустить T-10, не T-3 |
