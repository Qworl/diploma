# Defense Day Checklist — Защита ВКР

> Жизненный цикл подготовки. T = дата защиты.
> Источник: `docs/thesis/defense-prep/2026-05-24-design.md` §9, §13.

---

## За 3-4 недели (T-21..T-28)

- [ ] **Подтвердить тайминг защиты** с Судаковым В.А.
      (формат кафедры 806: 7-10 мин или 10-12 мин — от этого зависит compression слайдов)
- [ ] **Получить PDF задания на ВКР** от Крылова С.С. (зав. кафедрой 806)
      → положить в `report/extra/task.pdf`, раскомментировать `\includepdf` в `main.tex:34`
- [ ] **Проверить приказ об утверждении тем ВКР** — подписан ли
- [ ] **Зарегистрироваться в расписании ГИА**
- [ ] **Уточнить рецензента** (кто, как связаться)
- [ ] **Аудит `reproduce.sh`** — запустить end-to-end, убедиться, что артефакты регенерируются

## За 2 недели (T-14)

- [ ] **Number sync ВКР завершён** (см. spec §3) — после стабилизации содержательной работы
- [ ] **Антиплагиат ≥ 80%** (заимствования ≤ 15%)
      — запустить ЗАРАНЕЕ, чтобы успеть переписать спорные места
- [ ] Финализация slides + speaker notes (после number sync)
- [ ] Тест-компиляция `slides/main.tex` и `report/main.tex` в PDF

## За 7-10 дней (T-7..T-10)

- [ ] **Нормоконтроль кафедры** (T-7..T-10, отдельная процедура)
- [ ] **Отзыв научного руководителя** (Судаков В.А.)
- [ ] **Рецензия рецензента**
- [ ] **Загрузка PDF ВКР в NTB МАИ** + электронная подпись
- [ ] **Pre-bake 3 demo-скриншота** в `images/demo_screenshots/`:
      - `demo_pasta_screenshot.png` — pasta SKU end-to-end с trace
      - `demo_chocolate_screenshot.png` — chocolate SKU
      - `demo_cheeses_screenshot.png` — cheeses SKU
      → заменить placeholder на slide 11

## За 2-3 дня (T-2..T-3)

- [ ] **Переплёт ВКР** в типографии:
      - 1 экземпляр обязательный (на стол комиссии)
      - 1 запасной (на случай потери / повреждения)
- [ ] **7 копий раздаточного материала** напечатаны (по числу членов комиссии):
      ```bash
      cd slides && pdfjam --nup 2x2 --landscape main.pdf -o handout.pdf
      ```
      затем распечатать 7×, степлером по углу
- [ ] **Распечатать speaker notes** (`slides/SPEAKER_NOTES.md`)
- [ ] **Тест ключевых шагов демо** (не full `reproduce.sh` — он длинный):
      - `python3 -m demo.ml_service.cascade --sku "De Cecco penne rigate 500g"`
      - запустить `notebooks/01_demo_live.ipynb` end-to-end
- [ ] **USB-backup** всех файлов (slides.pdf, main.pdf, *.ipynb, scripts)
- [ ] **Финальная репетиция** — прогон 10-минутной речи 3 раза, замер тайминга

## День защиты (T-0)

### Утром

- [ ] Ноутбук **полностью заряжен** + зарядка с собой
- [ ] **USB-backup** в кармане
- [ ] **Распечатанные слайды** (full-page) на случай отказа проектора
- [ ] **Распечатанные slides handout** (4-up, A4) — для членов комиссии
- [ ] **Распечатанный антиплагиат-отчёт**
- [ ] **Справка о загрузке в NTB МАИ**
- [ ] **Распечатанные speaker notes**
- [ ] **Документы:** паспорт, зачётка, студенческий
- [ ] **Backup-слайды проверены:** пройти B1-B7 за 5 мин, убедиться что прочитываются

### На месте

- [ ] **Прийти за 30 мин до начала** — найти аудиторию, проверить проектор
- [ ] **Подключить ноутбук к проектору**, проверить разрешение, фокус
- [ ] **Открыть** `slides/main.pdf` в полноэкранном режиме
- [ ] **Открыть в фоне** `notebooks/01_demo_live.ipynb` (на всякий случай)
- [ ] **Открыть в фоне** запасной браузер с github-репо (если демо упадёт — показать код)

### Во время защиты

- Говорить **громко и медленно**
- **Безличные конструкции** — «реализовано», «получено», не «я сделал»
- **Замена англицизмов** — каскад / запасной слой / порог / отказ от ответа
- На слайдах 9-10 — **замедлиться**, дать комиссии прочитать таблицы
- При вопросе из backup B1-B7 — листнуть до соответствующего слайда

### После защиты

- [ ] Сохранить все распечатки (на случай апелляции)
- [ ] Отдать переплетённый экземпляр секретарю комиссии
- [ ] Отметиться в журнале защит

## Что взять с собой (физически)

| Категория | Предмет |
|---|---|
| Документы | Паспорт, зачётка, студенческий, отзыв, рецензия, антиплагиат-отчёт, NTB МАИ-справка |
| Печатные | 1 переплетённый ВКР, 1 запасной, 7 копий handout, full-page слайды, speaker notes |
| Электроника | Ноутбук, зарядка, USB-backup, переходник HDMI/USB-C (если нужно) |
| Прочее | Вода, ручка, чистый лист бумаги |

## Известные точки отказа и fallback

| Что | Fallback |
|---|---|
| Проектор не работает | Раздать handout, показывать на ноутбуке поочерёдно членам комиссии |
| Ноутбук разрядился | USB → попросить ноутбук у научного руководителя |
| Демо упало | Слайд 11 со скриншотами уже в PDF — не запускать live |
| Вопрос из не-backup области | «Запишу вопрос для уточнения после защиты — материалы есть в репозитории по QR на slide 14» |
| Жюри просит конкретное число, которого нет в слайдах | «Это число доступно в исполняемом ноутбуке главы 3.3 — могу показать после защиты» |
