## Сборка PDF

Из директории `latex/`:

```bash
make all      # MD → LaTeX → PDF одной командой
make convert  # только MD → LaTeX
make pdf      # только LaTeX → PDF (xelatex + biber)
make clean    # удалить .aux/.bbl/.log и пр.
```

Требуется: `latexmk`, `xelatex`, `biber` (входят в MacTeX, TeX Live, MiKTeX).

## Требования

- ГОСТ 7.32-2017: шрифт Times New Roman 14pt, межстрочный 1.5, отступ 1.25 (зашиты в шаблоне).
- Объём основной части ≥ 60 стр. (Введение + главы 1–4 + Заключение).
- Оригинальность ≥ 80 %, заимствования ≤ 15 %.
- Стиль безличный («В работе рассмотрено...»).
- Библиография по ГОСТ 7.1-2003 (стиль `gost-numeric` через `biblatex`).
