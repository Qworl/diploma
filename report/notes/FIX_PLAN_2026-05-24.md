### 1.8 `src/eval/cocoa_percentage_labelspace_fix.py` *(новый, ~30 минут)*
**Проблема:** silver хранит `cocoa_percentage` в buckets («50-70», «70-85»), LLM возвращает raw число («70%»). Automatic mismatch при evaluation, занижает LLM accuracy на этом attr.

**Fix:** при evaluation bucketize LLM output в silver-labelspace:
```python
def bucketize_cocoa(raw_value: str | float) -> str | None:
    n = parse_percent(raw_value)  # extracts "70" from "70%" or "dark chocolate 70%"
    if n is None: return None
    if n < 50: return "lt_50"
    if n < 70: return "50-70"
    if n < 85: return "70-85"
    return "85_plus"
```
