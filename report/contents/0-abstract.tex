\abstract
\keywords{ОБОГАЩЕНИЕ ТОВАРНЫХ ДАННЫХ, КАСКАДНАЯ АРХИТЕКТУРА, ОБУЧЕНИЕ СО СЛАБОЙ РАЗМЕТКОЙ, БАЙЕСОВСКАЯ СЕТЬ, БОЛЬШАЯ ЯЗЫКОВАЯ МОДЕЛЬ, КАЛИБРОВКА, ИЗВЛЕЧЕНИЕ ПРИЗНАКОВ, ВЕКТОРНЫЕ ПРЕДСТАВЛЕНИЯ}

\textbf{Объект исследования.} Процесс автоматизированного обогащения товарных каталогов интернет-магазинов с использованием открытых источников данных.

\textbf{Предмет исследования.} Гибридная каскадная архитектура с ансамблевой оценкой уверенности классификаторов и адаптивным обращением к большой языковой модели как запасному слою.

\textbf{Цель работы.} Разработать гибридную каскадную систему обогащения товарных данных для интернет-магазина с высокой точностью и стоимостью ниже прямого вызова большой языковой модели.

\textbf{Методы.} SBERT-векторизация, градиентный бустинг XGBoost с поатрибутными порогами уверенности, байесовская сеть, запасной слой на большой языковой модели; трёхъярусная эталонная разметка с консенсусом независимых языковых моделей; разбиение без пересечения товарных кодов.

\textbf{Результаты.} Пятислойная гибридная каскадная система на трёх категориях пищевых продуктов: 93,0~\% сквозной точности при обращении к большой языковой модели лишь на 4,1~\% ячеек из 16\,360; только-каскадная точность — 95,5~\%, по независимой ручной разметке — 86,7~\%. Система доминирует по Парето над прямым вызовом: +9,2~п.~п. точности, стоимость ниже в 580 раз (в режиме «каскад + Gemini 2.5 Flash» относительно прямого Claude Sonnet 4.5; архитектурный вклад каскада — 24 раза).

\textbf{Область применения.} Системы управления товарной информацией (PIM) интернет-магазинов: автоматизация заполнения атрибутов карточек, снижение ручной нагрузки оператора в 12–25 раз; в локальном сценарии на открытой модели gpt-oss-120b — работа без передачи данных во внешние сервисы.
